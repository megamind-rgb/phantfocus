Changes to Python

The app runs its tracker on Python 3.12.14, as built by python-build-standalone (release 20260924, “install only, stripped”). To keep the app small, we removed parts it doesn’t use: the test suite, IDLE, Tcl/Tk and tkinter, turtle, pip and ensurepip, lib2to3, C headers, build settings and compiled caches. We didn’t change any Python source code.
